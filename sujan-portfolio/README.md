# Sujan M S - Portfolio
Static site (HTML, CSS, JS). No install or build needed.

- Run: open `index.html` in a browser (or use VS Code "Live Server").
- Photo: put your picture at `assets/photo.jpg` (initials show until then).
- Edit details in `index.html`; colours are the variables at the top of `style.css`.
- Deploy free: drag the folder to Netlify Drop, or push to GitHub and enable GitHub Pages / Vercel.
